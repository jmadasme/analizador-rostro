# rec/ — video explicativo

Este directorio contiene el video asciinema de **Analizador de rostro: video en vivo desde un Arduino UNO Q** y el reproductor
que se usa en la página del proyecto.

- `analizador-rostro.cast`: grabación original (asciicast v2).
- `analizador-rostro.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:16. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
